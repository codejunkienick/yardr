A wagon here waits for a person: Christopher decides. No agent works this
stage. The wagon carries the question and the options, written by whoever sent
it here; if it does not, ask them before deciding.

A wagon leaves once the answer is on it, as a note. The stage has no outcomes;
the person answering moves it (`yardr review -g decisions`, or
`yardr bead advance <id> --to <stage>`):

- to `new`, when a builder can now finish it;
- to `backlog`, when the answer changes what the wagon is and the yardmaster must
  reshape it. An answer that changes the train is a note on the train too.
