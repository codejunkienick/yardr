When this yard's work is a website on this pack, whose beads deploy after they land and close only when the site is live.

- **Deploys.** Landed is not live: `merged` deploys the base to the site's Void
  platform, and a bead closes at `live`. A deploy that fails goes to `decide`
  with the end of the Void CLI's output, and mails you. The code has landed, so
  fix forward with a bead. A rollback (`void project rollback`), the pause of
  the deploy group and the deploy token are the operator's to run themselves;
  how: `yardr pack show website`.
- A chain deploys each bead as it lands, so make a train when half of the work
  must not be seen: its children stay off the base and nothing deploys until
  the whole is reviewed and merged. When else, and how: `yardr docs line a
  chain or a train`.
- Watch `--stage merged` for what has landed and is not live, beside the stage
  the base has you watch.
- Ask before anything outward-facing or hard to undo: a live site is both.
